
# Финансовый анализатор транзакций

Приложение для анализа банковских операций с конвертацией валют и логированием.

## Функциональность

* Чтение финансовых операций из JSON‑файла.
* Конвертация сумм из USD и EUR в рубли по текущему курсу.
* Логирование операций с ротацией файлов.
* Сокрытие чувствительных данных через `.env`.
* Обработка ошибок и краевых случаев при чтении данных.

Новые функции: чтение JSON‑файлов с транзакциями

Реализована функция для безопасного чтения финансовых операций из JSON‑файла.
Функция read_transactions_from_json

Расположение: src/utils/json_reader.py

Назначение:

    чтение транзакций из JSON‑файла;

    обработка ошибок (отсутствие файла, битый JSON, права доступа и т. д.);

    логирование операций и ошибок.

Параметры:

    file_path (str) — путь к JSON‑файлу.

Возвращает:

    список словарей с данными о транзакциях;

    пустой список при ошибках.

Обработка ошибок:

    файл не найден;

    файл пустой;

    содержимое не является списком;

    битый JSON;

    нет доступа к файлу (PermissionError);

    неподдерживаемая кодировка (UnicodeDecodeError).

Примеры использования

Базовый вызов:
```python

from src.utils.json_reader import read_transactions_from_json

file_path = 'data/operations.json'
transactions = read_transactions_from_json(file_path)
print(f'Прочитано транзакций: {len(transactions)}')
```
Обработка результата:
```python

if transactions:
    for transaction in transactions:
        print(f'Транзакция #{transaction.get("id")}: {transaction.get("amount")} {transaction.get("currency")}')
else:
    print('Транзакции не найдены или произошла ошибка чтения файла')
```

Конфигурация ruff

Настройки линтера находятся в pyproject.toml в секции [tool.ruff]:
toml

    [tool.ruff]
    select = ["E", "F", "I"]  # базовые правила: ошибки синтаксиса, импорты
    ignore = ["E501"]         # игнорируем длинные строки (если нужно)
    line-length = 88         # длина строки
    target-version = "py38"  # целевая версия Python

    Сравнение с Flake8
    Параметр	ruff	Flake8
    Скорость	В 10–100 раз быстрее	Медленнее
    Правила	Включает правила Flake8, isort, pyupgrade	Только базовые правила
    Исправления	Автоматическое исправление (--fix)	Требуется отдельный инструмент
    Конфигурация	Единый конфиг в pyproject.toml	Отдельные файлы
