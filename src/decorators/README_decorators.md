# Документация: декоратор логирования, его тестирование и запуск


## 1. Описание декоратора


Декоратор `@log` предназначен для автоматического логирования вызовов функций. Он выполняет следующие задачи:
- фиксирует время начала выполнения функции;
- записывает статус завершения (`ok` или `error`);
- поддерживает запись логов в файл или в консоль;
- сохраняет контекст (имя функции, аргументы).


**Пример использования:**

```python
@log(filename="mylog.txt")
def my_function(x, y):
    return x + y
```

2. Структура реализации

Расположение:
```src/decorators/log_decorator.py.```

Ключевые компоненты:
```
    log(filename=None) — фабрика декораторов с параметром пути к файлу лога;

    wrapper(*args, **kwargs) — обёртка, добавляющая логирование;

    обработка исключений с записью в лог.
```
3. Тестирование декоратора

Расположение тестов: tests/test_log_decorator.py.

3.1. Проверяемые сценарии

Успешное выполнение функции:
    проверка записи функция ok в лог;
    валидация возвращаемого значения.

Обработка ошибок:
    запись функция error: ТипОшибки при возникновении исключения;
    перехват и повторное выбрасывание исключения.

Работа с аргументами:
    передача *args и **kwargs без искажений;
    тестирование функций с разными сигнатурами.

Логирование в файл:
    создание файла лога по указанному пути;
    проверка содержимого файла после вызова.

Логирование в консоль:
    использование capsys для перехвата вывода;
    поиск шаблонов времени и статуса.

3.2. Примеры тестов
```python

def test_log_success_console(capsys: CaptureFixture[str]):
    """Проверка логирования успешного вызова в консоль."""
    assert success_func(2, 3) == 5
    captured = capsys.readouterr().out
    assert re.search(
        r'\[\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}\]success_func ok', captured)


def test_log_error_file(log_file: Path):
    """Проверка записи ошибки в файл."""
    @log(filename=log_file.name)
    def error_func():
        raise ValueError("Test error")

    with pytest.raises(ValueError):
        error_func()

    content = log_file.read_text(encoding='utf-8')
    assert 'error_func error: ValueError' in content
```
