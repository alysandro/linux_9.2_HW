Описание проекта

Проект предоставляет инструменты для обработки финансовых данных с учетом обработки ошибок и исключений.
Основные компоненты
1. Маскирование данных (Masks)

Модуль масок отвечает за обработку конфиденциальной информации:

    Маскирование карт:

        Формат: XXXX XX** **** XXXX

        Валидация минимум 10 цифр

        Обработка ошибок

    Маскирование счетов:

        Формат: ** XXXX

        Отображение только последних 4 цифр

2. Генерация данных (Generators)

Модуль генераторов отвечает за создание тестовых данных:

    Генератор номеров карт:

        Создание валидных номеров карт в формате XXXX XXXX XXXX XXXX

        Поддержка диапазонов генерации

        Валидация входных параметров

        Обработка ошибок

python

from src.generator import card_number_generator

# Пример использования
for card in card_number_generator(1, 5):
    print(card)  # Вывод: 0000 0000 0000 0001 ... 0000 0000 0000 0005

3. Обработка транзакций (Processing)

Модуль обработки транзакций:

    Фильтрация по состоянию (EXECUTED/CANCELED)

    Фильтрация по валюте

    Сортировка по дате

    Обработка ошибок

4. Виджеты (Widget)

Модуль виджетов обеспечивает:

    Форматирование дат

    Маскирование информации

    Валидацию данных

Компонент генераторов
card_number_generator

Основные характеристики:

    Принимает диапазон генерации (start, end)

    Форматирует номера в стандартный формат банковских карт

    Валидирует входные параметры

    Генерирует последовательность номеров

Ограничения:

    start должен быть ≥ 1

    end не может превышать 9999999999999999

    start не может быть больше end

Обработка ошибок генераторов

Возможные исключения:

    ValueError при некорректных параметрах

    StopIteration при завершении генерации

Документация по генераторам
Параметры генератора

    start: начальное значение диапазона

    end: конечное значение диапазона

    формат вывода: XXXX XXXX XXXX XXXX

Примеры использования
python

try:
    # Корректная генерация
    for card in card_number_generator(1000, 1010):
        print(card)
except ValueError as e:
    print(f"Ошибка генерации: {e}")
