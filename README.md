## Утилиты чтения финансовых данных

Документация по модулям чтения данных из CSV и Excel‑файлов в `src/utils/`.

---
### Работа с данными (CSV)
Добавлена поддержка загрузки транзакций из CSV-файлов:
*   **`load_transactions_from_csv(file_name)`**:
    *   Автоматически ищет файл в директории, указанной в `DATA_DIR`.
    *   Проверяет корректность расширения (.csv) и физическое наличие файла.
    *   Использует `pandas` для гибкого определения разделителей.
    *   Возвращает данные в формате **list[dict]**, что обеспечивает полную совместимость с логикой обработки JSON-транзакций.
    *   Все этапы (успех, отсутствие файла, ошибки формата) фиксируются в логах через `csv_reader` логгер.



### Модуль чтения CSV‑файлов (`csv_reader.py`)

**Расположение:** `src/utils/csv_reader.py`

#### Функция `load_transactions_from_csv`

**Назначение:** загрузка транзакций из CSV‑файла, расположенного в директории `DATA_DIR`.

**Параметры:**
* `file_name` (`str`) — имя CSV‑файла (должен находиться в директории, указанной в `DATA_DIR` из `constants.py`).

**Возвращает:**
* список словарей с данными транзакций (`list[dict]`) при успешном чтении;
* пустой список (`[]`) в случае ошибок.

**Особенности реализации:**
* проверка расширения файла (должно быть `.csv`, регистронезависимо);
* проверка существования файла и того, что это именно файл (а не директория);
* автоматическое определение разделителя в CSV (`sep=None`, `engine='python'`);
* преобразование DataFrame в список словарей (`to_dict('records')`) для совместимости с другими модулями (например, `json_reader`);
* логирование операций через именованный логгер `'csv_reader'`;
* обработка исключений без прерывания работы приложения.

**Обрабатываемые ошибки:**
* неверное расширение файла;
* файл не найден или не является файлом;
* ошибки чтения CSV (битый файл, неверный формат и т. д.).

**Логирование:**
* информация о начале чтения файла;
* количество успешно прочитанных транзакций;
* детальные сообщения об ошибках с трассировкой.

#### Пример использования

```python
from src.utils.csv_reader import load_transactions_from_csv

# Загрузка транзакций из файла transactions.csv
csv_data = load_transactions_from_csv('transactions.csv')

if csv_data:
    print(f'Прочитано транзакций: {len(csv_data)}')
    print('Первые 2 записи:', csv_data[:2])
else:
    print('Не удалось загрузить данные из CSV‑файла')
```
### Модуль чтения Excel‑файлов (xlsx_reader.py)

### Работа с данными (Excel)
**Добавлена поддержка электронных таблиц:**
*   load_transactions_from_xlsx(file_name)**:
*   Поддерживает форматы **.xlsx** и **.xls**.
*   Использует движок `openpyxl` для корректного чтения современных Excel-файлов.
*   Аналогично CSV-модулю, возвращает список словарей (`list[dict]`), что позволяет использовать данные в существующем коде без конвертации.
*   Ошибки формата или отсутствие файла логируются через именованный логгер `xlsx_reader`.


#### Расположение: **src/utils/xlsx_reader.py**

#### Функция load_transactions_from_xlsx

Назначение: загрузка транзакций из Excel‑файла (.xlsx или .xls), расположенного в директории DATA_DIR.

Параметры:

  ```python
  file_name (str) # имя Excel‑файла (должен находиться в директории, указанной в DATA_DIR).
  ```
**Возвращает:**

*   список словарей с данными транзакций (list[dict]) при успешном чтении;
*   пустой список ([]) в случае ошибок.

Особенности реализации:


*    поддержка форматов .xlsx и .xls (регистронезависимо);
*    проверка расширения файла перед обработкой;
*    проверка существования файла и его типа;
*    использование pandas.read_excel() для чтения данных;
*    преобразование DataFrame в список словарей (to_dict('records'));
*    логирование через именованный логгер 'xlsx_reader';
*    обработка исключений с возвратом пустого списка.

**Обрабатываемые ошибки:**

*    неверное расширение файла (не .xlsx и не .xls);
*    файл не найден или не является файлом;
*    ошибки чтения Excel (битый файл, проблемы с кодировкой, неверный формат и т. д.).

**Логирование:**

*    информация о начале чтения файла;
*    количество успешно прочитанных транзакций;
*    детальные сообщения об ошибках.

Пример использования

```python

from src.utils.xlsx_reader import load_transactions_from_xlsx

# 1. Загрузка из современного формата .xlsx
xlsx_data = load_transactions_from_xlsx('transactions_excel.xlsx')
if xlsx_data:
    print(f'Прочитано из .xlsx: {len(xlsx_data)} транзакций')
    print('Примеры первых 2 записей:', xlsx_data[:2])

# 2. Загрузка из старого формата .xls
xls_data = load_transactions_from_xlsx('operations.xls')
if xls_data:
    print(f'Прочитано из .xls: {len(xls_data)} транзакций')
    print('Примеры первых 2 записей:', xls_data[:2])
```
**Общие особенности модулей чтения файлов**

**Сходства csv_reader и xlsx_reader:**

    единый формат вывода данных — список словарей (list[dict]), что обеспечивает совместимость с другими компонентами системы;
    строгая проверка входных данных (расширение, существование, тип файла);
    детальное логирование всех операций и ошибок;
    обработка исключений с безопасным возвратом пустого списка;
    использование именованных логгеров для чёткой идентификации источника логов;
    зависимость от pandas для чтения данных и logging для логирования.

**Требования к окружению**

**Необходимые зависимости:**

    pandas — для чтения CSV и Excel;
    logging — для логирования (встроенная библиотека Python).

**Настройка путей:**

    Убедитесь, что DATA_DIR (из constants.py) указывает на корректную директорию с файлами данных.
