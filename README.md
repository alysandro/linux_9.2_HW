## Функция "get_mask_card_number(card: str) -> str:
` Функцию маскировки номера банковской карты.  Выводит в формате:  XXXX XX** **** XXXX`

Принимает список словарей и опционально значение для ключа state
(по умолчанию'EXECUTED'). Функция возвращает новый список словарей, содержащий только те словари,
у которых ключ state соответствует указанному значению.

## Тестирование функций

В проекте реализованы юнит‑тесты для проверки корректности работы следующих функций из модуля `src.main`:

- `divide(a, b)` — деление двух чисел;
- `reverse_string(s)` — реверсирование строки.

### Структура тестов

Тесты написаны с использованием фреймворка **pytest**.

1. **`test_divide()`**
   Проверяет корректность работы функции деления на нескольких тестовых случаях:
   - деление `2` на `1` даёт `2`;
   - деление `3` на `3` даёт `1`.

2. **`test_reverse_string(value, expected)`**
   Тестирует функцию реверсирования строки с помощью параметризованных тестов (`@pytest.mark.parametrize`).
   Покрыты следующие сценарии:
   - обычная строка (`'123'` → `'321'`);
   - строка с буквами (`'hallo'` → `'ollah'`);
   - другая строка (`'world'` → `'dlrow'`);
   - пустая строка (`''` → `''`);
   - одиночный символ (`'a'` → `'a'`);
   - палиндром (`'111'` → `'111'`).

### Зависимости

Для запуска тестов требуется:
- Python (с поддержкой `from __future__ import annotations`);
- библиотека `pytest`.
